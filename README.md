# Mohammad Omar Nurshad: academic portfolio

GitHub Pages site. `index.html` is the portfolio; `documents.html` is the document library, driven by `documents.json`.

## Add a document
1. Redact IDs, serial/roll/registration numbers, dates of birth, parents' names and unneeded signatures, and flatten the PDF to images.
2. Put the PDF in `documents/<folder>/`.
3. Add an entry to `documents.json` (same fields as the others) with `"status": "available"`. Use `"pending"` for a listed document with no public copy yet.

## Never commit
Recommendation letters, identity documents, draft statements, financial documents, application correspondence, the submitted manuscript, the examiner copy of the thesis. A public repository cannot keep files private.
